KEY FEATURES
============

1. Bio Generation
   - User inputs rough description
   - Gets 3 polished professional variations
   - Copy/apply with one-click

2. Skill Description Enhancement
   - Input skill name + proficiency level
   - Get 3 descriptions tailored to level
   - Manual edit or AI suggestion

3. Circle Blurb Creation
   - Input circle name + topic
   - Get 3 engaging community descriptions
   - Apply to circle profile
